# Overview

Repertoire Score computes a single, transparent, adjustable per-clonotype score by
combining several component signals — abundance, somatic-mutation load, generation
probability, and clonotype convergence — into one composite value used to rank and
select clonotypes.

The score is a first-class column that lead selection and downstream blocks discover
generically, and whose composition (component signals and their weights) the user can
inspect and adjust.
